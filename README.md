# University Merch Tinder (Выбор мерча для нового сезона)
## О проекте 
Веб-приложение для студентов колледжа и университета, позволяющее в интерактивном формате оценивать варианты мерча для следующего сезона (свайпы право/влево) и проходить короткий опрос о предпочтениях в цветах и деталях одежды.

Проект помогает организаторам собирать точную статистику и понимать, какую  именно линейку одежды стоит запускать в производство.

## Структура проекта 
* 'app.py' - главный файл сервера на Python (Flask)
*  'database.sqlite' - база данных для хранения мерча, анонимных голосов и ответов опроса.
*  'templates/' - HTML-шаблоны страниц (главная со свайпером, страница опроса, панель администратора).
*  'static/' - стили CSS и скрипты JavaScripts для интерфейса


  ## Как будет реализована идея 
  1. **Анонимная идентификация:** Пользователь заходит на сайт без регистрации, система вписывает ему безопасный токен в браузере для защиты от накрутки голосов.
  2. **Интерактив (Свайпер):** карточки товаров с возможностью лайкнуть/дизлайкнуть вещь.
  3. **Анкета:** Опрос с выбором любимых цветов и деталей одежды + поле для свободных идей.
  4. **Админ-панель:** Закрытая страница с графиками, процентами популярности вещей и возможностью выгрузки статистики.
