Tinder для мерча МГРИ
Веб-приложение для инерактивного голосования за университетский мерч в формате свайпов.

Инструкция по локальному запуску
Выполни эти команды в терминале VS Code в корневой папке проекта:

1. Создай виртуальное окружение:
   '''powershell
   python -m venv venv

2. Активируй его:
   Windows(PowerShell):
   venv\Scripts\Activate

3. Установи зависимости:
   pip install -r requirements.txt

4. Запусти приложение:
   python app.py
   После запуска открой ссылку http://127/0.0.1:5000

Безопасность
Статистика: Скрытый раздел админ-панели защищен авторизацией.
Защита от накруток: при нажатии кнопки "Пройти заново" предыдущие голоса текущего пользователя удаляются из базы данных.
